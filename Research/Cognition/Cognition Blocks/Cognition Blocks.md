# Cognition Blocks

How a cognition type is defined, how a block is placed and used on a board, and what structure a type can carry. Foundation → Growing with the thought, and Terms.

## Settled

- A cognition type is Stem's named shape for a recurring way of working: its sections and its visual design.
- A type is defined off the board and has one definition. A variation is a new type with its own name.
- Changing a type affects only blocks created afterwards. Existing blocks keep the structure they were created with.
- Idea, Learning, and Action are the first types.
- Stem never moves a thought into a block on its own.

## Open questions

- **What a section is.** The Learning example has four — parked, forks, notes, loops — some plain text, some interactive. The set of section kinds a type can be built from is undefined.
- **Placing a block.** The keyboard path from an empty point on the board to a block of a chosen type.
- **The definition surface.** Where and how types are defined and changed off the board.
- **Freeform to block.** Whether, and how, a user moves existing freeform content into a block.
- **Kinds of cognition.** A proposed distinction between "hot" and "cold" cognition has two readings — a property of the thought (live versus settled) or of the method (thinking inside a block's structure versus building structure by hand). Both words already mean something else in psychology: thinking shaped by emotion versus emotionally neutral processing. Unresolved, including whether the distinction is needed.

## Findings

- **Each block carries its own structure.** Because a type change affects only new blocks, a block holds a copy of the structure it was created with rather than a reference to its type's current definition.
