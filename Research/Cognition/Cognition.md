# Cognition

The research behind Foundation's four pillars: the meta layer, recollection, cognition blocks, and the integrations built on them. Why Stem needs them is [Foundation](../../Foundation.md)'s to say, and this document does not restate it. It holds what only the set can show: where the topics meet, and what would prove the set wrong.

The topics are independent. Each develops and promotes on its own schedule.

---

## Why together

Each pillar is affordable only because of another. Thoughts can stay unfiled because recollection finds them without filing. Cognition blocks give thinking a structure the meta layer can read. An integration is a cognition block onto an outside system. Developed apart, each would make assumptions the others break.

## What would falsify it

The initiative claims that these pillars together make messy, unfiled thinking workable over months, not just minutes. It fails if:

- **Recollection cannot find what was not filed.** If you start naming and tagging so that you can find things again, filing has come back, and the first and third pillars fall together.
- **Cognition blocks become forms.** If a block is something you fill in rather than think in, its structure is administration, which is what Foundation set out to remove.
- **The meta layer shows nothing the board does not.** If looking from one step back reveals no more than looking at the board, the layer is decoration.
- **AI output is mistaken for yours anyway.** If the visual rule cannot be held in practice, Ownership fails, and with it the reason to trust anything else here.
